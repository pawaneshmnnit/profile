# Pawanesh Kumar Vishwakarma — Academic Homepage

Personal research homepage of **Pawanesh Kumar Vishwakarma**, Ph.D. Research Scholar,
Department of Computer Science & Engineering, MNNIT Allahabad.

Research areas: egocentric (first-person) vision, embodied AI, and multimodal learning.

**Live site:** https://pawaneshmnnit.github.io/profile/

## Structure

```
.
├── index.html      # single-page site (About · News · Research · Contact)
├── css/
│   └── style.css   # all styles + light/dark theming
├── js/
│   └── main.js     # theme toggle, mobile menu, BibTeX copy
├── pic2.jpg        # profile photo
└── README.md
```

Plain static HTML/CSS/JS — no build step. Hosted with GitHub Pages.

## Editing

- **Add a publication:** copy an `<article class="pub">…</article>` block in `index.html`
  and update the title, authors, venue, links, and the `<pre class="pub__bib">` BibTeX.
- **Add a news item:** copy a `<li class="news__item">…</li>` block in the News section.
- **Colours / fonts:** edit the CSS variables at the top of `css/style.css`.
